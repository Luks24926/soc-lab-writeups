# SOC Lab Writeups

A collection of hands-on incident investigation writeups from TryHackMe's SOC Simulator and other blue-team labs, documenting my process for triaging alerts, investigating suspicious activity, and writing incident reports.

## What's here

Each writeup includes:
- Investigation process and reasoning
- Evidence and analysis
- Final verdict (True Positive / False Positive)
- Incident report in analyst-ready format
